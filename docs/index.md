### Project Overview
HAJJ-SHIELD combines 5G network slice security, AI-driven crowd anomaly detection, emergency alert integrity verification, and pilgrim data privacy into a single operations platform.

### Modules
1. **5G Slice Security** - DDoS detection with Random Forest
2. **AI Crowd Anomaly Detector** - Isolation Forest per zone
3. **Emergency Alert Integrity** - HMAC + NLP verification
4. **Pilgrim Privacy Shield** - Fernet encryption + RBAC
5. **Central Dashboard** - Live operations view
6. **Demo Scenario** - Hajj Day 3 Emergency Drill
